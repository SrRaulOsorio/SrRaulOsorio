## `01` // Sobre mí

Soy Tecnólogo en **Análisis y Desarrollo de Software (SENA)** y desarrollador enfocado en construir soluciones web, APIs y sistemas orientados a resolver necesidades reales.

Me interesa especialmente el desarrollo backend, la arquitectura de software, las API REST y el diseño de soluciones mantenibles. También tengo experiencia trabajando en interfaces web y conectando frontend, backend y bases de datos.
